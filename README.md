# GoIT Neoversity: Реляційні бази даних
## Домашнє завдання до Теми 5: Вкладені запити та повторне використання коду

Цей репозиторій містить рішення домашнього завдання, присвяченого роботі з вкладеними запитами, оператором CTE (WITH) та створенням користувацьких функцій у MySQL.

### Опис завдань

1. **Вкладений запит у SELECT**: Отримання `customer_id` з таблиці `orders` для кожного рядка `order_details`.
2. **Вкладений запит у WHERE**: Фільтрація деталей замовлень за конкретним перевізником (`shipper_id = 3`).
3. **Вкладений запит у FROM**: Розрахунок середньої кількості товару для відфільтрованих даних з використанням тимчасової таблиці.
4. **Використання CTE**: Аналогічний розрахунок середнього значення, але з використанням оператора `WITH`.
5. **Користувацька функція**: Створення функції `divide_func` для ділення значень та її застосування до таблиці.

### Технології
- MySQL 8.0+
- MySQL Workbench

### Структура репозиторію
- `solution.sql` — повний файл з SQL-кодом усіх завдань.
- Скриншоти результатів виконання (пронумеровані згідно з вимогами).

### Як запустити
1. Імпортуйте базу даних, що використовується в курсі.
2. Скопіюйте вміст файлу `solution.sql` у MySQL Workbench.
3. Виконуйте запити по черзі. 
*Примітка: для створення функції в 5-му завданні переконайтеся, що ваш клієнт підтримує зміну DELIMITER.*
